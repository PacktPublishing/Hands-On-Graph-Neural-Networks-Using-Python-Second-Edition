# Chapter 3 – Creating Node Representations with DeepWalk

## Running it

```bash
cd Chapter03
python run.py
python figures/generate_figures.py
```

`run.py` took 32 seconds on the machine this was verified on, CPU only.

7 figures, listed in [figures/INDEX.md](figures/INDEX.md). Regenerate them with the command above; they are drawn in grayscale, as printed.
