# Chapter 18 – Building a Recommender System Using LightGCN

## Running it

```bash
cd Chapter18
python run.py
python figures/generate_figures.py
```

`run.py` took about 6 minutes on the machine this was verified on, CPU only.

## Figures

3 figures, listed in [figures/INDEX.md](figures/INDEX.md). Regenerate them with the command above; they are drawn in grayscale, as printed.
