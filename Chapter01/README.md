# Chapter 1 – Getting Started with Graph Learning

Why a graph is worth the trouble: what it represents that a table does not,
what a GNN is asked to predict, and how it computes an answer. The chapter is
conceptual, so there is no `run.py` — the only code here draws the figures.

## Figures

4 figures, listed in [figures/INDEX.md](figures/INDEX.md).

Regenerate them with:

```bash
cd Chapter01
python figures/generate_figures.py
```

They are drawn in grayscale, as printed. `matplotlib` and `numpy` are the only
dependencies.

Figure 1.1 is not here: it was accepted as supplied and has no source in this
repository, so the chapter's printed figures come from two places.
